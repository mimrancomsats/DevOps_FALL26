Getting inside the Running Container
-----------------------------------------------------

1. sudo bash
2. docker run -d --name httpd_c httpd
3. docker exec -it httpd_c bash (Gets you inside the running container)
4. ls (shows all files and folders of the httpd Web server)
5. cd ..
6. cd ..
7. cd ..
8. ls (shows you the list of files in Linux OS)
9. exit

Task 1 - Sharing One Named Volume between Mutiple Containers
----------------------------------------------------------------
1. Create a named volume called sharedvol.
2. Mount it to a container named httpd_c1.
3. Create file1, file2, and file3 inside the volume.
4. Create another httpd container named httpd_c2.
5. Mount the same volume to /containervol.
6. Verify that httpd_c2 can see the files created by httpd_c1.
7. Create file4 from httpd_c2.
8. Verify that httpd_c1 can see file4.

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
Task 2 - Creating Volumes using Docker Volume Command.
----------------------------------------------------------------
1. Create a Docker volume named webdata using the docker volume command.
2. Verify that the volume has been created.
3. Run an httpd container named httpd_named and mount webdata at /containervol.
4. Access the running container using docker exec.
5. Navigate to /containervol.
6. Create three files:
file1
file2
file3
7. Verify that the files exist inside the container.
8. From the host, locate the webdata volume and verify that the three files exist in its _data directory.
9. Stop and remove the container.
10.Create another httpd container and mount the same webdata volume at /containervol.
11.Verify that file1, file2, and file3 are still available.

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
Task 3 - Creating Volumes using Dockerfile.
----------------------------------------------------------------
1. Create a directory named docker-volume-practice.
2. Inside it, create a file named Dockerfile.
3. Use ubuntu:latest as the base image.
4. Install apache2.
5. Create a directory /app/data.
6. Use the Dockerfile VOLUME instruction to define /app/data as a volume.
7. Start Apache when the container runs.
8. Build the image with the name volume-image.
9. Run a container named volume-container.
10.Enter the running container and create three files inside /app/data:
file1.txt
file2.txt
file3.txt
11.Verify that the files exist.
12.Remove the container.
13.Run a new container from the same image and check whether the files are still present.
14.If you want the same data to appear in the second container, create a named volume and mount it.
